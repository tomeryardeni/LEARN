## 1. רקע ומטרות

### 1.1 רקע

אפיון SpecLab מתאר מערכת למידה מלאה: מסלול בשכבות, מעבדות, מנטורים וניהול תוכן. מערכת כזו דורשת צוות פיתוח, שרת וכותבי תוכן, ולוקח זמן עד שהיא זמינה.

המסמך הזה מגדיר גרסה שאפשר להשתמש בה כבר עכשיו: קובץ HTML אחד שרץ בדפדפן, בלי שרת ובלי התקנה, ומכסה את הליבה של SpecLab בשני מצבים.

### 1.2 מטרת המערכת

| מצב | למי | מה הוא נותן |
|---|---|---|
| **מצב משחק (SpecQuest)** | מי שרוצה 5 עד 10 דקות של תרגול קליל, גם בנייד | שאלות קצרות במבנה של עולמות ושלבים, עם נקודות, לבבות, רצף ימים ותגים. כל שאלה מלמדת מושג אחד ומסבירה את התשובה |
| **מצב מקצועי (SpecLab Pro)** | מי שרוצה לתרגל כמו בעבודה | ארבע מעבדות מתוך SpecLab: מעבדת ERD, ארגז חול SQL, מעבדת שדות וממשקים, וסימולציית "המפתח שואל" |

שני המצבים משתפים את אותה מפת מיומנויות (סעיף 5.3 באפיון SpecLab), כך שתרגול במשחק ובמעבדות מזין תמונת מצב אחת.

### 1.3 יעדים מדידים

| יעד | מדד | ערך יעד מוצע |
|---|---|---|
| הרגל | שיעור המשתמשים עם רצף של 5 ימים לפחות בחודש הראשון | 40% ומעלה |
| למידה | שיעור תשובות נכונות בניסיון חוזר על שאלה שנענתה בטעות | 80% ומעלה |
| מעבר למקצועי | שיעור המשתמשים שהשלימו עולם במשחק ופתחו מעבדה במצב מקצועי | 30% ומעלה |
| עצמאות באפיון | מספר שאלות המפתח לכל 1,000 מילים, בין הסימולציה הראשונה לחמישית | ירידה של 40% |

ערכי היעד מוצעים. בגרסה הזו אין שרת, ולכן המדדים נמדדים אצל המשתמש בלבד (מסך ההתקדמות).

| כרטיס הסבר | ההסבר שמוצג אחרי כל תשובה: למה זה נכון, ואיך הטעות נראית בעבודה |

### 5.2 סוגי שאלות במשחק

| סוג | מה המשתמש רואה | מה הוא עושה | דוגמה |
|---|---|---|---|
| בחירה | שאלה ו-4 תשובות | בוחר אחת | "מה ההבדל בין מפתח עסקי למפתח פנימי?" |
| נכון או לא | טענה | נכון / לא נכון | "מק"ט עם אפס מוביל יישמר כמספר שלם" |
| קרדינליות | שתי ישויות ומשפט עסקי | בוחר קרדינליות לכל צד | "ספק ↔ הזמנת רכש" |

### 5.3 מיומנויות נמדדות

משתמשים ב-11 המיומנויות מסעיף 5.3 באפיון SpecLab, ללא שינוי. כל שאלה ותרגיל משויכים למיומנות אחת.

### 5.4 תרחישים במצב המקצועי

| תרחיש | שימוש |

## 7. כללים עסקיים

כללי SpecLab שחלים כפי שהם: Business Rule 4 עד 13, 16 עד 18, 23, 25. כללי המשחק:

| מזהה | כלל | מודולים |
|---|---|---|
| Game Rule 1 | עולם 0 פתוח מההתחלה. עולם נפתח כשנאספו לפחות 2 כוכבים בכל שלב בעולם הקודם, וניצחון במבחן הבוס שלו | 2 |
| Game Rule 2 | בכל שלב 3 לבבות. תשובה שגויה מורידה לב. כשנגמרים הלבבות השלב נכשל, וה-XP שנצבר בו נשמר | 2 |
| Game Rule 3 | כוכבים בסיום: 3 לבבות = 3 כוכבים, 2 = 2, 1 = 1. נשמר הציון הטוב ביותר בכל שלב | 2 |
| Game Rule 4 | תשובה נכונה = 10 XP. Combo: מהתשובה הנכונה השלישית ברצף, כל תשובה נכונה מקבלת 5 XP נוספים. סיום שלב = 20 XP לכל כוכב | 2, 4 |
| Game Rule 5 | במבחן בוס אין רמזים, יש 3 לבבות, ו-8 שאלות מכל שלבי העולם. ניצחון = 100 XP | 2 |
| Game Rule 6 | רמה = 1 + floor(√(XP / 50)). שם הרמה: 1–2 מתלמד, 3–4 מאפיין צעיר, 5–6 מאפיין, 7–8 מאפיין בכיר, 9+ ארכיטקט | 4 |
| Game Rule 7 | הרצף גדל באחד ביום שבו הושלם שלב או תרגיל, ומתאפס אם עבר יום שלם בלי פעילות | 4 |
| Game Rule 8 | שאלה שנענתה בטעות נכנסת לרשימת החזרה, ויוצאת ממנה אחרי שתי תשובות נכונות רצופות בה | 2 |
| Game Rule 9 | "מה הלאה": אם יש 6 שאלות ברשימת החזרה, מוצע שלב חזרה. אחרת, השלב הפתוח הראשון שלא הושלם. אם הכל הושלם, המעבדה במיומנות עם הציון הנמוך ביותר | 1 |
| Game Rule 10 | ציון מיומנות = ממוצע נע: ציון חדש = 0.7 × ציון קודם + 0.3 × תוצאה (0 או 100 בשאלה, הציון בתרגיל). ציון ראשון = התוצאה הראשונה | 9 |
| Game Rule 11 | תרגיל במעבדה מזכה ב-XP לפי הציון: ציון × 1. צפייה בפתרון לפני ניסיון שני מבטלת את ה-XP לתרגיל | 4–8 |
| Game Rule 12 | מפתח API לא נכלל בייצוא ההתקדמות | 10 |
