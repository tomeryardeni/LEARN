# SpecQuest — לומדים אפיון טכני

משחק ומעבדות ללימוד אפיון טכני, מבוסס על מסמך האפיון העסקי של SpecLab.

## הפעלה

פותחים את הקובץ **`speclab.html`** בדפדפן (לחיצה כפולה). זהו.
אין צורך בהתקנה, בשרת או באינטרנט. ההתקדמות נשמרת בדפדפן.

- **🎮 מצב משחק** — 5 עולמות לפי שכבות המסלול, שלבים של 6 שאלות, לבבות, XP, רצף ימים ותגים.
- **🔬 מצב מקצועי** — מעבדת ERD, ארגז חול SQL (מנוע SQLite מובנה), מעבדת שדות וממשקים, וסימולציית "המפתח שואל".
- **🤖 בינה מלאכותית (אופציונלי)** — בהגדרות אפשר להזין מפתח Anthropic API. בלי מפתח הכל עובד עם בדיקות כללים.

## פיתוח

הקוד נמצא ב-`app/src`, והבנייה מאחדת הכל (כולל מנוע ה-SQL) לקובץ HTML אחד:

```bash
npm install      # פעם אחת
npm run build    # בונה את speclab.html
npm test         # בדיקות לוגיקה ותוכן
npm run docs     # מייצר את קובץ ה-Word מתוך ה-Markdown
```

| קובץ | תפקיד |
|---|---|
| `app/src/core.js` | מצב, כללי משחק (XP, רמות, רצף, מיומנויות), ניתוב, רכיבי UI, לקוח AI |
| `app/src/sqlengine.js` | הרצת sql.js ב-Web Worker עם מגבלת 5 שניות וחסימת פקודות כתיבה |
| `app/src/game-content.js`, `game.js` | בנק השאלות ומצב המשחק |
| `app/src/lab-*.js` | ארבע המעבדות |
| `app/src/app.js` | מסכי בית, התקדמות והגדרות |

הוספת שאלות: עורכים את `app/src/game-content.js` ומריצים `npm run build`.
